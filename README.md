# Currency Converter Project

## Project Title
Currency Converter Using Python

## Project Description
This project is a simple currency converter developed using Python 3. It converts an amount from one supported currency to another using predefined exchange rates.

## Supported Currencies
- INR - Indian Rupee
- USD - US Dollar
- EUR - Euro
- GBP - British Pound

## Exchange Rates
- 1 INR = 1 INR
- 1 USD = 83 INR
- 1 EUR = 90 INR
- 1 GBP = 105 INR

## Features
1. Converts between supported currencies.
2. Uses a dictionary to store exchange rates.
3. Uses functions for currency conversion.
4. Validates currency codes.
5. Handles invalid amount inputs.
6. Does not accept negative amounts.
7. Displays results up to 2 decimal places.

## Technologies Used
- Python 3
- Visual Studio Code

## Functions Used
- `convert_to_inr()` - Converts the given amount into INR.
- `convert_currency()` - Converts one currency into another currency.

## How to Run the Project

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python main.py
```

4. Enter the amount.
5. Enter the source currency.
6. Enter the target currency.
7. View the converted result.

## Conclusion
This project helps users understand basic Python programming concepts such as dictionaries, functions, conditions, operators, and exception handling.

**Note:** The exchange rates are predefined and are not live market rates.
